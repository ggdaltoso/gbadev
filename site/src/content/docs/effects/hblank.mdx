## When to use it

Water that ripples, heat over a desert, a sky with more colors than a palette holds, a split screen. Any effect where the top of the screen and the bottom should have different settings in the same frame.

## How to think about it

**The screen is drawn one line at a time.** The GBA draws 160 lines, and pauses for a moment after each one. That pause is the H-Blank.

**An H-Blank effect changes a setting in that pause.** Butano runs a small routine in fast memory on every H-Blank, which moves the next value from your array to a hardware register. It's a little CPU time, 160 times per frame.

**Each class is one setting that varies per line:**

| Class | What varies per line |
|---|---|
| `bn::regular_bg_position_hbe_ptr` | A background's position |
| `bn::bg_palette_color_hbe_ptr` | A background palette color |
| `bn::bg_palettes_transparent_color_hbe_ptr` | The backdrop color |
| `bn::rect_window_boundaries_hbe_ptr` | A window's sides |
| `bn::blending_fade_alpha_hbe_ptr` | The fade alpha |
| `bn::sprite_position_hbe_ptr` | A sprite's position |

There are more, for almost every setting. For a setting they don't cover, there's [HDMA](/effects/hdma/), a different mechanism.

**Your array is the effect.** You give it 160 values, one per line. The effect keeps a reference to your array, and reads it again each frame only if you say so. To animate, change the values and tell it.

## The smallest thing that works

Each line of the map shifts left or right by a sine wave, and the wave moves a little each frame. **A** makes the waves bigger. The hero and the text stay still, because they aren't part of the background.

## Pitfalls

**The picture doesn't change, or changes once.**
You updated the array and didn't call `reload_deltas_ref()`. The other effects have their own `reload_..._ref()`, too.

**Garbage on screen, or a crash, after a scene change.**
The array died before the effect did. The effect holds a reference, not a copy, so declare the array first, as the snippet does, and C++ destroys the effect first.

**The array has the wrong size.**
It needs exactly `bn::display::height()`, 160, values, even if you only care about a few lines. Leave the others at 0.

**The game stops when you add one more.**
"No more H-Blank effects available": there can be 6 at a time by default. `BN_CFG_HBES_MAX_ITEMS` raises it.

**The whole game got slower.**
Each active effect takes time on every line, and the loop that fills 160 values isn't free either. Use `bn::degrees_lut_sin`, as the snippet does, instead of computing a sine, and don't rebuild arrays that haven't changed.

**Sprites don't ripple with the map.**
This effect only moves one background. `bn::sprite_position_hbe_ptr` does the same for a sprite.
