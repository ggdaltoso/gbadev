export const lines = Array.from({ length: 16 }, (_, i) => i * 10);
export const sky = (line) => {
	const red = 2 + Math.floor((line * 29) / 159);
	const green = 6 + Math.floor((line * 12) / 159);
	const blue = 24 - Math.floor((line * 18) / 159);
	return `rgb(${red * 8}, ${green * 8}, ${blue * 8})`;
};

## When to use it

When you need a value in memory to change on every screen line and [an H-Blank effect](/effects/hblank/) doesn't cover it. Here, a sky with 160 colors on a single palette entry. For anything Butano already has an effect for, use the effect: it's simpler and safer.

## How to think about it

**DMA is a copy the hardware makes for you.** It moves memory without the CPU running a loop. HDMA is the mode that copies a little during each [H-Blank](/effects/hblank/#how-to-think-about-it), the pause after each screen line.

**You give it an array and a destination.** `bn::hdma::start(source, destination)` copies from the array to that address, one line at a time, every frame, until you stop it. The array must hold 160 values, or a multiple of that if you write more than one per line.

**It's a low-level tool.** The destination is a raw address. Nothing checks that it makes sense, and Butano doesn't know you changed it.

**How it differs from an H-Blank effect:**

| | [H-Blank effect](/effects/hblank/) | HDMA |
|---|---|---|
| Who copies | A small routine, run by an interrupt | The DMA hardware |
| What it can change | The settings that have a class | Any memory address |
| At most | 6, by default | 1, plus 1 high priority |
| Knows about Butano | Yes | No |

## The smallest thing that works

A sky behind the hero. Nothing here is a background: the gradient is the backdrop, the color behind every layer, which has one palette entry. HDMA changes that entry 160 times per frame. **A** turns it on or off.

## Pitfalls

**The top line of the screen has the wrong color.**
HDMA copies after a line is drawn, so `sky[0]` shows up on line 1, and line 0 gets the last value of the array. The snippet shifts its values by one line for that.

**Garbage on screen after the array goes away.**
HDMA holds a reference, not a copy. Stop it before the array dies, or keep the array alive for as long as HDMA runs.

**The source has the wrong size.**
It has to be a multiple of 160 values, and if it's more than 160, each line gets that many values, which are written to consecutive addresses.

**Audio crackles.**
The high priority version, `bn::hdma::high_priority_start`, can cause issues with audio, as Butano's header warns. Use the normal one unless you need it.

**"Not supported by the audio backend".**
HDMA needs a DMA channel, and some audio backends use it. The default one, maxmod, leaves it free.

**The gradient doesn't show behind a background.**
The backdrop only shows where nothing is drawn. Any tile with a color other than index 0 hides it. To paint a color inside a background, write to that color's palette entry instead.

**A flat color stays after you stop it.**
The entry keeps the last value HDMA copied. Set the backdrop again with `bn::bg_palettes::set_transparent_color` if you want a specific one.
