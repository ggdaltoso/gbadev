## When to use it

A flashlight in a dark room, a minimap with a hard edge, a dialog box that hides what's behind it, a door that wipes the screen open. Anything that shows different layers in different parts of the screen.

## How to think about it

**A window says what shows inside it.** It's not a picture, and it draws nothing. It's a region of the screen with a list: this background yes, that one no, sprites yes or no, blending yes or no.

**There are four:**

| Window | Shape | Get it with |
|---|---|---|
| Internal | A rectangle | `bn::rect_window::internal()` |
| External | A rectangle | `bn::rect_window::external()` |
| Sprites | Wherever sprites with `set_window_enabled(true)` have pixels | `bn::window::sprites()` |
| Outside | Everywhere else | `bn::window::outside()` |

**Every pixel belongs to one of them.** If two overlap, internal wins over external, and both win over the sprites window. What's left is outside.

**They all start by showing everything.** So a window does nothing until you hide something. The usual way is what the snippet does: hide things in *outside*, and leave them on inside the rectangle.

## Pitfalls

**The HUD disappeared.**
`set_show_sprites(false)` hides every sprite in that window, and text is sprites too (see [the HUD page](/basics/hud/)). That's why this snippet has no text. To keep a HUD visible, hide things another way, or give the HUD its own window.

**Black isn't what shows behind.**
Where every layer is hidden, you see the backdrop. Set it with `bn::bg_palettes::set_transparent_color`.

**The window stays behind when the camera moves.**
Boundaries are in screen coordinates. Either move them by hand, as here, or attach the window to a camera with `set_camera`.

**A soft edge isn't possible.**
Windows are all or nothing, pixel by pixel. For a circle or an odd shape, use the sprites window, or change the boundaries line by line with [an H-Blank effect](/effects/hblank/).

**Blending stops inside a window.**
Each window also has `set_show_blending`. If an effect turns off in one region, check that list.

**A window never shows up.**
Its boundaries start out empty. Set them before expecting anything.
