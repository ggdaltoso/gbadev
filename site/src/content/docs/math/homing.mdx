export const rad = (d) => (d * Math.PI) / 180;
export const fly = (maxTurn) => {
	let x = 40, y = 20, heading = 90;
	const points = [[x, y]];
	for (let frame = 0; frame < 400; ++frame) {
		const target = Math.atan2(70 - y, 330 - x) * 180 / Math.PI;
		let difference = target - heading;
		while (difference >= 180) difference -= 360;
		while (difference < -180) difference += 360;
		heading += Math.max(-maxTurn, Math.min(maxTurn, difference));
		x += Math.cos(rad(heading)) * 1.5;
		y += Math.sin(rad(heading)) * 1.5;
		points.push([x, y]);
		if (Math.abs(x - 330) < 3 && Math.abs(y - 70) < 3) break;
	}
	return points.map(([px, py]) => `${px.toFixed(1)},${py.toFixed(1)}`).join(' ');
};

## When to use it

For anything that should chase: missiles that follow the player's plane, a bee that comes after the hero, a magic bolt that finds the nearest enemy. A chaser that points straight at its target every frame can't be escaped, and that isn't fun. One that can only turn so fast curves after its target, overshoots when the target dodges, and has to come round again. That turn rate is the knob between "dodgeable" and "deadly".

[Bullet patterns](/math/bullets/) has the angles and the velocity from a cosine and a sine; this page adds a heading that changes.

## How to think about it

**A missile keeps a heading, and turns it a little each frame.** Its heading is an angle in degrees, kept between frames like a [velocity](/math/velocity/). Each frame, `bn::degrees_atan2` gives the angle to the ship, and the heading turns toward it, but by no more than `max_turn`, 1.5 degrees. Then the missile moves 1.5 pixels along its heading. Without the limit the heading would just be the angle to the ship, and the missile would fly straight at it.

**Turn the shortest way round.** The angle to the ship minus the heading isn't the turn yet: from a heading of 170° to a target of 190°, written as -170° by `atan2`, the difference is -340°, which would mean turning almost all the way round the other way. `turn_between` adds or takes 360 until the difference is between -180 and 180: here, +20°. Then the limit is applied to that.

**The sprite turns with the heading, the other way.** The missile is an affine sprite: `set_rotation_angle` turns it, and Butano turns counterclockwise, while the headings grow clockwise because the screen's y grows down. The art points up, which is heading 270, so the rotation is `270 - heading`, wrapped. A test ROM that launched the missiles straight to the right showed the nose in front, where the missile was going.

## The smallest thing that works

Some of the C++ in the snippet:

| In the code | Why |
|---|---|
| `bn::clamp(turn_between(...), -max_turn, max_turn)` | The turn rate limit in one line: the shortest turn, cut to the range a missile can manage in a frame. |
| `flying.sprite.set_rotation_angle(...)` | Makes the sprite affine. Each rotated sprite with its own angle uses one of the 32 affine matrices, so 8 missiles fit easily. |
| `velocity * missile_speed` | `bn::fixed_point` times `bn::fixed`: both coordinates scaled, a direction of length 1 made 1.5 long. |
| `int life = missile_life;` | A default member value: `{ sprite, 90 }` sets the first two members, and `life` starts full. |
| `bn::erase_if(missiles, ...)` | Missiles out of fuel are removed after the loop, not inside it: erasing inside a range-based `for` over the same vector would break the loop under it. |

## Pitfalls

**A missile with no turn limit can't be dodged.**
The snippet and a test ROM that pointed each missile straight at the plane every frame got the same keys: seven short swerves to the right and back. The snippet was hit 7 times; the test ROM, 13. Its missiles turned as fast as the plane swerved, so a swerve never made one miss.

**Missiles circle instead of coming.**
A test ROM that turned by the raw difference, without wrapping it to -180..180, got the same keys as the snippet: the plane up to the top left corner, then still. The snippet's missiles kept reaching the plane, from 3 hits to 7. The test ROM's stayed at 3: its missiles came from below and to the right, where the angle to the plane is written near -180 while the heading is near 180 (worked out, not printed), and they turned the long way, looping at the bottom right until their fuel ran out.
