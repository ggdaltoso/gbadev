---

:::note
This is an **unofficial** guide. It is not affiliated with Butano or its author.
For signatures and the full API, the [official Butano docs](https://gvaliente.github.io/butano/) are the source of truth.
:::

Butano's docs tell you *what* every class does. This guide starts from "I want to do X" and shows which Butano pieces you need, in what order, and where they bite.

Every page has the same five parts: when to use it, how to think about it, the smallest thing that works, pitfalls, and where to read more. Every snippet is built by `make` in the guide's [`snippets/`](https://github.com/ggdaltoso/gbadev/tree/main/snippets) project.

Start with [the game loop](/basics/game-loop/).
