:::note
This is an **unofficial** guide. It is not affiliated with Butano or its author.
For signatures and the full API, the [official Butano docs](https://gvaliente.github.io/butano/) are the source of truth.
:::

Butano's docs tell you *what* every class does. This guide starts from "I want to do X" and shows which Butano pieces you need, in what order, and where they bite.

Every page has the same five parts: when to use it, how to think about it, the smallest thing that works, pitfalls, and where to read more. Every snippet is built by `make` in the guide's [`snippets/`](https://github.com/ggdaltoso/gbadev/tree/main/snippets) project, and every page runs its snippet in your browser: press its **Run** button and play it with the keyboard.

The pages are in four sections:

- **The basics:** what almost every game needs. The game loop, input, sprites, backgrounds, the camera, collision, text, saves and sound.
- **Effects:** what the hardware can do to the picture. Blending, windows, mosaic, rotation, line-by-line effects, shake, particles.
- **Structure:** how to organize a game as it grows. Scenes, game objects, state machines, files, performance, replays.
- **Math:** the numbers behind the motion. Fixed point, vectors, hitboxes, velocity, easing, line of sight, pathfinding.

Start with [the game loop](/basics/game-loop/).
